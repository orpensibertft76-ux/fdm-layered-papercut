# FDM 分层剪纸
## 有仓库管线时先复跑样板

如果当前项目包含 `pipeline/run.py` 和 `examples/rooster/job.json`，先按根目录 README 和 AGENTS.md 用保存的鸡款图稿复跑，对照 `examples/rooster/expected/` 的路径叠合与核验结果。接着用同一入口处理新款，保留本次核验记录。单独安装技能时，生成与切片所用的代码和固定样板可 [从项目仓库获取](https://github.com/orpensibertft76-ux/fdm-layered-papercut)。


## 先定交付和结构

从参考图和用户要求确认这轮是拆层稿、结构验证、模型还是摆盘。用户要求先验证结构时，在生成生产模型前检查单片连通、上下层遮挡和框内装配。

每张图案片按同一画面原点和外围定位边建模。交付整张剪纸时，每张薄片的全部图案须在该片内通过实体连到定位边，可以独立拿起。板上一个对象可能包含多个不相连的实体。叠装后有背柱托住的图案也可能仍是散件。

## 裁定画口

分色前先区分画芯纹样与实体外框。参考图自带展示用外框、留白或阴影时，裁到实际画口对应的纹样外沿，另存裁切图并叠回参考图核对。龙款以画内金边外沿为画口，金边留在图案片内，外围红框由盒体决定。画内同色纹样仍参与分片。定位环在建模时按盒腔尺寸另加，放在压边下面。裁切图作为色表、面积评估、分层和叠合验证的共同输入。

## 清理分色图

以用户认可的原图为底稿，先保留构图、姿态、主要纹样和装饰密度。展示图保留光影，分色源稿用固定实物色表和清楚的实色边界。自动量化后放大逐区检查，高光、渐变和边缘晕染可能留下断线、杂点或假小孔。先把细节归入连续背片的露色窗口、连成一体的前片或可遮挡的宽搭接。需要改画时只处理具体问题位置，保存原图与处理稿的同尺度对照。

## 先定层序

从分色图提取各色在画口内实际可见的纹样。先标出必须保持的露色、通孔及局部前后关系，再排层序。默认把可见面积大、连续纹样多、自身容易接框，并且能盖住多条下层接筋的色片放在靠前的位置。按遮罩检查候选片的可见面积、主体连通范围、可用接边位置和实际遮筋范围。边框、压边下的定位环、被挡住的留料及整面背板不计入可见图案面积。底色和承托背板按其功能放在后侧。

从最前片向后安排接框。最前片优先利用已有纹样接框；后面各片先沿上片实心区下面保留宽搭接，只有连续底料走不到定位边时才补接筋。面积大但分散的色片，如果靠前会新增明显横筋，优先放到能遮住它的连续片后面。层序变化后重算每一张片的开孔和连料。

用原层序和新层序的实际遮罩比较正视露色、目标斜视下的整筋遮挡，以及新增可见接筋和窄颈。选能保住原画并减少可见接筋的顺序。在固定色数不足以表达局部前后关系时，再考虑同色分到不同深度。龙款 006 的金框、金鳞网和金焰连续范围较大，因此金片放在暖白片前方，利用它们遮住白片的接筋。

## 选择拆法

**默认采用整片开孔，充分留料。** 中后层从整片出发，先保留能被前片遮住的连续底料和宽搭接，再开出露底色、真通孔和装配所需的位置。优先保证每张片能独立拿起、窄颈有足够宽度、叠合后露色正确。用料和重量只作记录，只有用户明确提出省料或减重时才用它们筛选方案。

遇到斜看串色或装配干涉，先试调整层序、上片覆盖或开孔边界，必要时对问题位置局部收边，每次收边后复查连通和遮挡。最前片沿可见纹样接定位边。分别标记露底窗口和真通孔。

详细操作、祥羊用料数据及阴刻阳刻的关系见 [两种拆法与取舍](references/split-methods.md)。

## 拆层和连筋

1. 先画正视叠合图，标明从背到前的层序、每层单色、露下层颜色的开孔、必须保留的通孔和框口。按遮挡关系重画轮廓。同色可跨部位合并，但先核对羊蹄压莲、主体压背景这类局部前后关系。把阴影和碎高光归并到有意义的色块，保留主体轮廓和关键留白。
   - 先铺大块颜色，再用前面的片开孔露色。例如羊眼、腿纹和角肋间的红色共用连续红羊底，白片和金片分别开孔。拆层时画出能通到框的花瓣、卷叶或水纹，留好这些连接再镂空。
2. 逐片求连通域并标出外围所属区域。孤岛优先沿本层已有轮廓、上层实心投影和框口压边下方走筋。优先用短筋、多处搭接或局部方格，视可遮挡面积选择。筋与纹样及定位边要有实质重叠和可打印的窄颈。薄片须平放打印，连筋也应由盘面支承。
   - 中后层优先利用整片开孔后剩下的连续底料接框，缺少连接时在前片能遮住的位置补宽。前层优先用纹样接框。多层可共用部分花瓣轮廓，让前层遮住后层的连接。每次局部修边后，重新检查每一块都能走到框。
3. 用最终各层遮罩及真实层高核对新增筋的完整宽度。先正视，再按目标侧视角检查。候选筋没有遮挡余量时，先调整层序、上片覆盖或局部纹样。最前片没有上片遮挡，可把必要连接融入云尾、卷毛、莲瓣或边纹，并在预览标明这些可见修改。无法同时保住原轮廓、整片连通和隐藏连接时，说明具体冲突并给出可核对的修改稿。
4. 设计框内共同定位边和压边。按装配坐标检查片间顺序、定位间隙、总厚、框口压住的范围及通孔。按当前设备和材料选薄片厚度、筋宽及装配间隙。此工作区的 FDM 尺寸决策遵循项目规则和设计参考。

## 交付前核验

- 拆层阶段保存每片实心与空白图、增设筋位置和叠合图。用实际连通结果标出还未接到外框的区域。候选遮挡区只用于寻路。
- 实体阶段逐片核对有且只有一个连通实体，并检查窄颈、边界边、非流形边、方向、尺寸和正体积。比较最终网格与验证用遮罩，尤其留意细筋在轮廓简化、挤出和导出时是否消失。遮挡检查注明使用的几何或栅格、视角和余量。
- 用户要求一盘一个时，按实体清单逐盘平放，每盘一个实际连通件。保留每片单色，框、压边、脚座按实际件数分盘。按项目工具链做原生 3MF 回读，核对盘数、网格连通、实际几何、尺寸、朝向、盘面位置和耗材。按用户指定的阶段交付，写清已做的检查及切片、实物试印状态。
- 要求实际切片时，逐盘回读 G-code 和工艺配置。放大查看实际挤出路径中的窄筋、细孔和关键纹样，记录断线、并线、缩孔或尖端丢失，并核对路径是否仍接到定位边。路径覆盖预览是估算，实物强度、变形和配合需试印验证。
- 实际切片的默认审阅图用逐片累加叠合。按实物装配顺序从背向前，每格在上一格之上加一张色片的实际挤出路径，标明序号及本步新增色片，使用统一画口和尺度。把原设计图裁到同一画口，放在最终叠合图旁。单盘路径图留作检查证据。
- 要看装配效果时，用本版已经回读的生产几何按实际层序、片厚、间隙和压边装起来。导入后核对尺寸、正面朝向及画口位置，再出正视和斜视。标明是装配渲染或实物照片。

要做侧视遮挡或复盘相似的整张剪纸任务时，读 [祥羊案例与踩坑](references/ram-case.md)。

遇到系列图稿返修、金边与盒框区分、交换层序或切片后检查时，读 [卷云龙试跑](references/dragon-case.md)。

要判断哪些层适合网格、哪些层适合顺着纹样接框，读 [《年年有鱼》与《金缕祥羚》拆法对照](references/two-works.md)。与用户沟通时，先说每张保留了什么、盖住了什么、怎么连成一张。
