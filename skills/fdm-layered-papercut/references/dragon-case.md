# 卷云龙试跑

以卷云十二生肖 001 龙格为视觉基准。当前仓库保留最终龙款与鸡款案例。编号过程可查 Git 历史。

| 版本 | 遇到的问题 | 下次怎样处理 |
| --- | --- | --- |
| 002 大色块重绘 | 删鳞、卷纹和装饰后，配色相近但系列风格偏离 001。 | 先用少数款做同尺度校样。保留图案密度，优先局部处理反光、模糊边界和具体结构问题。 |
| 003 原图量化 | 构图保住了，深浅绿、鳞网、白腹和云边仍出现脏色、断线和碎区。 | 建立固定色表后逐区归并。龙鳞用金网开窗露绿，腹节用白腹和金分隔表达，眼口露深底，珠焰用金片开口露连续朱红片，云卷按前后关系露金或白。逐一检查小色区的实际承载片和接框路径。 |
| 004 局部补宽 | 把用料和斜视变化作为综合选型指标，选出的薄底结构仍有明显白筋。 | 整片开孔充分留料作为默认。用料只记录。用正视和目标斜视逐段核查整根筋，同时记录窄颈和孔洞。 |
| 005 整片开孔 | 白片在最前，左云到龙腹、龙首上方和下沿必须外露接筋。 | 先评估每色可见范围、天然连通和遮筋能力。最前片尤其依赖已有纹样通向定位边。 |
| 006 金色最上 | 金片遮住主要白筋，旧图外围装饰红框却占用画口。为绕过它，顶部仍露短金筋。 | 层序变化后重算开孔及补料。画口在分色前定好，裁掉盒体将提供的外框。 |
| 007 裁到金边 | 金边直接成为画芯轮廓，主要白筋被遮住，顶部短金筋离开画口。 | 保留金边和画内红纹。按盒体单独生成外边与定位环。用装盒斜视确认盒框厚度、压边及叠层露色。 |

## 核对交付图

- 007 的六片顶层挤出路径栅格各为一个连通域。检查时还需查看金鳞孔、白腹节和须梢的局部路径。路径栅格差异受线宽与取样影响，不能直接当作缺料率。
- 装配模型曾因 GLB 导入换算出现 1000 倍尺寸偏差，镜头只看到一块红面。导入后先比对盒外宽、画口和总厚，按实际源尺寸修正预览比例，再看相机是否朝向金片一侧。007 案例盒外宽 192.8 mm、画口 180 mm、总厚 10.5 mm，这些是本款核对值。
- 斜视渲染保留真实几何和叠片顺序，光照只用于展示。实物试印记录单独维护。
