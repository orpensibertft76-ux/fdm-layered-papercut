# 生图交接规范

使用支持参考图编辑的图像模型。将用户认可的原稿作为编辑输入，填写下列内容。鸡款实际用过的完整提示词见 [prompt.txt](../examples/rooster/prompt.txt)，原图与模型输出也在同目录。

```text
编辑随附的原设计图。保留 [姿态、构图、装饰和主要纹样]。
输出正视方形分色图，裁到 [内边纹样] 的外沿。外盒颜色由实际盒体提供。
固定六色 [每个色值及名称]。使用实色硬边，保留纹样密度，去除高光、阴影、渐变和游离杂点。
[最前候选色] 的 [相连纹样] 向定位边延伸，通过 [自然搭接] 遮住后层连接。
[细纹、眼睛或花心] 用前片开孔露出 [连续背片颜色]。保留足够宽的显色带和连接区域。
输出一张方形 PNG。保持画口平直、四边完整。
```

工具调用需要实际附图。可使用 AI 环境内置的参考图编辑工具，或本机已配置的等效模型。密钥通过所用工具的本地配置提供。模型输出到本机后再选择一张进入程序，生成接口与本地分片程序之间以 PNG 文件交接。

`art_crop` 和 `reference_crop` 采用各自图像左上为原点的像素框 `[左,上,右,下]`，右下为开区间。两张图各自核对画口。六色从背到前，首色为整张背板，末色为最前片且覆盖画口边缘。程序按固定色表归色，会清理少量小色岛。逐图放大核查眼鼻、尖角、花心和细带，具体问题用局部改图修正。
## 给 AI 的工具调用顺序

1. 读取参考图并填写上面的提示词。调用当前环境的图像编辑工具，传入实际参考图附件、填写后的提示词和不透明背景。直接编辑一张参考图时，一次传一张。检查返回图再保存为 art.png。
2. 已有符合规格的 art.png 时，直接进入分片。复跑样板时用随仓库保存的 art.png，生图模型的随机变化不会影响复跑。
3. 记录原图和生图输出各自的裁切框，填写背板到前片的颜色顺序。执行 README 的统一入口，等待核验完成。
4. 交付可编辑 3MF、逐片切片叠合与原设计对照。要求装盒效果时同时交装配斜视。用正斜视检查接筋、孔边和装饰保真。记录仍需实物确认的地方。
