# 008 鸡款试跑

以 001 鸡格为基准局部重绘，保留向左站姿、红冠、白胸、放射日芒、弧形尾羽、云浪及莲花。固定六色，画芯裁到金边。红色外边由托框和压边形成。

自背向前为墨黑、绿、红、橙、暖白、金。金色画边、日芒及尾羽弧线能利用自身轮廓接边，作为最前片。中后层采用整片开孔，保留上片能覆盖的连续底料。开孔分别露出鸡眼黑底、鸡冠及羽内红底、尾带绿与橙、胸和云纹的暖白。所有图案片遮罩各有一个实心连通域。胸羽短金接点及两处尾羽金线根部仍可见局部补接，斜视可见部分孔边底色。

沿用龙款的 180 mm 画口，六张片外宽 186 mm、厚 1.2 mm。托框外宽 192.8 mm。八盘每盘一个单色件，P1S／0.4 mm／PLA，层高 0.20 mm。未实物试印。

八盘均已实际切片并原生回读，几何、摆位和主要配置一致。六片顶层挤出路径各为一个连通域。预计 302.27 g、13 小时 36 分 28 秒。见[切片核验](切片/verification.json)、[路径叠合](实际路径叠合.png)和[装盒渲染](鸡_装盒斜视.png)。未发送打印。实体配合、窄筋强度、翘曲和独立三维自交待检查。
